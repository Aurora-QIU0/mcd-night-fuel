## 🕐 它解决的不是"吃什么"，而是"这个点该吃什么"

市面上的点餐助手都在**推荐好吃的**。但它回答不了这几个问题：

| 真实困境 | 这个 Skill 的答案 |
|---|---|
| 下午三点困得睁不开眼 | 给你**提神窗口**的最优组合（这时候喝咖啡最划算） |
| 凌晨 1 点，吃了怕睡不着 | 按你计划入睡的时间，反推该吃多少、几点前吃完 |
| 想提神，又怕咖啡因顶到天亮 | 算出**咖啡因最晚饮用时间**，过了点主动劝你换无咖啡因 |
| 预算有限还想吃饱 | 自动找券 + 算到手价，给最优组合 |
| 翻菜单翻 10 分钟选择困难 | 一句话输入，直接给**一个推荐 + 理由** |

> 麦当劳 MCP 的官方工具里**没有任何咖啡因 / 代谢相关能力**，也不区分时段。
> 这份「什么时候该吃什么」的策略层，就是这个项目补上的东西。

## ⏰ 核心机制：分时段策略

同一份菜单，在不同时段会被打出**不同的分**：

| 时段 | 时间窗 | 打分倾向 | 咖啡因策略 |
|---|---|---|---|
| 🌅 早餐 | 06:00–10:30 | 蛋白加权、热量放宽 | 开放 |
| 🍱 午市 | 10:30–14:00 | 蛋白加权、正餐热量 | 开放 |
| ☕ 下午茶 | 14:00–17:00 | **提神加权**、热量收紧 | **黄金窗口** |
| 🌆 晚餐 | 17:00–21:00 | 均衡、控钠 | 谨慎 |
| 🌙 深夜 | 21:00–01:00 | 热量↓ 钠↓ | 过截止点即关闭 |
| 🌃 凌晨 | 01:00–06:00 | 极轻负担 | **强制关闭** |

**越晚越保守**——它是少见的、会主动劝你少喝咖啡的点餐助手。

## ✨ 效果演示

### ☕ 下午茶 15:30 —— 困得不行

> 你输入：**现在 15:30，预算 20，下午困得不行**

| 项目 | 结果 |
|---|---|
| 🍔 推荐组合 | 板烧鸡腿堡 + 无糖可乐（小杯） |
| 💰 用券后价 | **¥18.0** |
| 🔥 营养 | 热量 420 kcal ｜ 蛋白 24 g ｜ 钠 980 mg |
| 💡 为什么是它 | 24g 蛋白质够扛，420 kcal 正合这个时段，34mg 咖啡因刚好提神 |
| ☕ 咖啡因 | 下午 2–4 点是黄金窗口：提神最好，且不影响夜间睡眠 |

### 🌙 深夜 23:40 —— 还在写代码

> 你输入：**现在 23:40，预算 35，还要写 2 小时，想提神但不想失眠**

| 项目 | 结果 |
|---|---|
| 🍔 推荐组合 | 双层吉士堡 + 雪碧（中杯） |
| 💰 用券后价 | **¥24.0** |
| 🔥 营养 | 热量 560 kcal ｜ 蛋白 27 g ｜ 钠 1240 mg |
| ☕ 咖啡因 | ⚠️ **已过最晚饮用时间（23:00）**，提神需求自动让位于睡眠质量 |
| 🔁 备选 | 板烧鸡腿堡 + 无糖可乐 ¥18.0（便宜 ¥6、更轻负担、咖啡因更少） |

### 🌃 凌晨 03:00 —— 饿得慌

> 你输入：**现在 3 点，饿得慌，随便垫一下**

| 项目 | 结果 |
|---|---|
| 🍔 推荐组合 | 双层吉士堡 + 雪碧（中杯） |
| ☕ 咖啡因 | 这个点绝对别碰咖啡因——天亮还要不要睡了？（**当前时段强制关闭**） |

> 💡 **最"反直觉"的地方**：你深夜还想灌咖啡时，它会直接劝你别喝，
> 并给出一套仍能扛饿的无咖啡因组合——把「休息质量」排在「当下提神」之上。
> 凌晨时段甚至会**在算法里**给含咖啡因的饮品打接近 0 分，不只是嘴上提醒。

## 🚀 快速开始

### 1. 申请麦当劳 MCP Token

1. 打开 <https://open.mcd.cn/mcp>
2. 右上角【登录】→ 手机号验证登录
3. 右上角【控制台】→ 点击【激活】申请 Token
4. 同意服务协议 → 复制 Token（**请妥善保管，不要提交到任何公开仓库**）

### 2. 配置 MCP 客户端

粘贴到你的 MCP 客户端（WorkBuddy / Cherry Studio / Cursor / Trae / VSCode），
**把 `${MCD_MCP_TOKEN}` 换成你的真实 Token**：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer ${MCD_MCP_TOKEN}"
      }
    }
  }
}
```

完整脱敏示例见 [`mcp-config.example.json`](./mcp-config.example.json)。

### 3. 使用

配置好之后，直接对 AI 说话 —— **不用一次性说全所有信息**：

```text
帮我点个麦当劳
```

也可以带上约束：

```text
现在23:40，预算35，还要写2小时代码，想提神但不想失眠，帮我推荐麦当劳
```

Skill 会按 [`SKILL.md`](./SKILL.md) 定义的流程自动编排 MCP 调用并输出方案。

### 4. 本地跑算法自测（不需要 MCP）

```bash
# 六个时段全跑一遍
python scripts/selftest.py

# 指定时段试
python scripts/recommend.py --demo --at 15:30

# 自定义输入（格式见 scripts/sample-input.json）
python scripts/recommend.py --stdin < scripts/sample-input.json
```

## 🧠 它是怎么想的

```text
用户输入（自然语言）
        │
        ▼
[1] now-time-info            判定时段：早餐/午市/下午茶/晚餐/深夜/凌晨
        │
        ├─► query-nearby-stores      定位门店
        ├─► query-meals              拉取在售餐品
        ├─► list-nutrition-foods     匹配营养数据
        ├─► query-store-coupons
        │   available-coupons        汇总可用券
        ├─► calculate-price          对候选组合算到手价
        │
        ▼
   生成候选组合（1 主食 + 1 配餐 + 1 饮品，4~6 个候选）
        │
        ▼
   scripts/meal_window.py    取出该时段的阈值与权重
        │
        ▼
   scripts/score_meals.py    五维打分（预算/蛋白/热量/钠/咖啡因）
        │
        ▼
   scripts/caffeine_model.py 咖啡因最晚饮用时间 = 入睡时间 − 3h
        │
        ▼
   输出「推荐 + 券后价 + 营养 + 咖啡因策略 + 备选差异」
        │
        └─► （用户确认后）create-order
```

**五维打分（权重随时段变化）**：

| 因子 | 说明 |
|---|---|
| 预算匹配 | 券后价越贴近预算越好，超预算重罚 |
| 蛋白质供给 | 抗饿关键，早餐 / 午市加权 |
| 热量适度 | 按时段的理想区间给分，深夜收紧 |
| 钠含量 | 过高影响睡眠与次日状态，深夜加权 |
| 提神需求 | 下午茶加权；越晚对「不必要的咖啡因」惩罚越重（凌晨系数最高） |

## 🔌 用到的麦当劳 MCP 能力

| Tool | 用途 | 必需 |
|---|---|:--:|
| `now-time-info` | 获取当前完整时间（时段判定基准） | ✅ |
| `query-nearby-stores` | 查询附近可用门店 | ✅ |
| `query-meals` | 查询门店在售餐品菜单 | ✅ |
| `query-meal-detail` | 查询套餐组成与可替换项 | ✅ |
| `list-nutrition-foods` | 餐品营养数据（能量/蛋白/脂肪/碳水/钠/钙） | ✅ |
| `query-store-coupons` | 当前门店可用优惠券 | ✅ |
| `available-coupons` | 可领取的麦麦省券列表 | ✅ |
| `auto-bind-coupons` | 一键领取可用券 | 建议 |
| `calculate-price` | 计算金额、配送费、优惠与应付总价 | ✅ |
| `create-order` | 创建订单（**仅在用户确认后调用**） | ✅ |
| `query-my-account` | 查询积分（可选，积分抵扣场景） | 可选 |

详细调用流程与业务价值见 [`MCP_INTEGRATION.md`](./MCP_INTEGRATION.md)。

## 🎯 目标用户

- **加班的程序员**：深夜既要提神又要保住睡眠质量
- **学生党**：预算敏感 + 时间约束
- **下午犯困的上班族**：需要一个"什么时候喝咖啡最划算"的答案
- **健身人群**：想吃又不想破坏当日热量目标
- **所有选择困难症**：一句话搞定，不用翻十分钟菜单
